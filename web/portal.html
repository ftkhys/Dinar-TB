    Jika ada kendala akses, hubungi petugas TB di fasilitas kesehatan Anda.

Apakah portal web dapat menggantikan aplikasi Android?+

Belum. Aplikasi Android saat ini mendukung konfirmasi obat dan pengingat. Portal web disiapkan sebagai pelengkap untuk Android dan iPhone.

Mengapa data pasien belum muncul di web?+

Data pasien hanya boleh ditampilkan setelah ada sesi web yang aman. Mekanisme tersebut belum tersedia, sehingga portal web belum membuka data pengobatan.

Bagaimana cara mendapatkan kode aktivasi?+

Hubungi petugas kesehatan yang menangani pengobatan Anda. Kode aktivasi diterbitkan oleh petugas dan hanya berlaku untuk perangkat yang diaktifkan.

Bisakah kode aktivasi Android dipakai untuk masuk ke web?+

Tidak. Kode aktivasi bersifat sekali pakai dan terikat pada perangkat. Memakainya di web dapat mengganggu akses aplikasi Android Anda.

Apakah notifikasi iPhone sama dengan Android?+

Belum tentu. Dukungan notifikasi web berbeda menurut browser dan sistem operasi. Aplikasi Android tetap menjadi jalur utama untuk pengingat saat ini.
