Keamanan dan privasi

Data pengobatan adalah data pribadi.

Dinar-TB hanya menampilkan informasi pengobatan kepada pasien yang berhak. Portal web memakai sesi aman berbasis cookie setelah kode aktivasi sekali pakai berhasil diverifikasi.

  • Jangan bagikan kode aktivasi

    Kode hanya diberikan oleh petugas kesehatan dan tidak boleh dibagikan melalui pesan atau media sosial.

  • Waspadai permintaan mencurigakan

    Dinar-TB tidak meminta kata sandi atau kode aktivasi melalui pesan singkat.

  • Hubungi petugas jika ragu

    Jika ada kendala akses, hubungi petugas TB di fasilitas kesehatan Anda.

Pertanyaan umum

Bantuan singkat.

Jika masih ada kendala, hubungi petugas TB di fasilitas kesehatan Anda.

Apakah portal web dapat menggantikan aplikasi Android?+

Portal web dan aplikasi Android sama-sama menampilkan data pengobatan. Konfirmasi obat dan jadwal pengingat mengikuti data yang sama dari petugas.

Bagaimana portal web melindungi data saya?+

Portal memakai sesi aman berbasis cookie HttpOnly setelah kode aktivasi diverifikasi. Setiap permintaan hanya dapat mengakses data pasien pemilik sesi.

Bagaimana cara mendapatkan kode aktivasi?+

Hubungi petugas kesehatan yang menangani pengobatan Anda. Kode aktivasi diterbitkan oleh petugas dan hanya berlaku sekali.

Apakah aktivasi web mengganggu aplikasi Android?+

Tidak. Aktivasi web membuat sesi browser terpisah dan tidak menonaktifkan atau mengubah perangkat Android yang sudah aktif.

Apakah notifikasi web tersedia di iPhone?+

Web Push di iPhone memerlukan iOS 16.4 atau lebih baru dan portal yang sudah ditambahkan ke Layar Utama melalui Safari.
